# ECLIPSE · R01–R07 训练成果公共审计报告

**2026-11-22 · 数据与模型训练研究（非发布）**

本报告把此前在本地完成、但未汇入 GitHub 的 R01–R07 训练研究结果整理成可追溯的公开证据。**全部研究候选均未晋级生产**。本审计文件和指标 JSON 主要记录聚合数值、权重哈希、来源与方法限制；**根据 Owner 后续明确要求，7 份实际 LightGBM 研究权重也已单独上传到 `Training/research/r07/checkpoints/`**。仓库仍不包含原始真人棋谱、40 组私人历史局面、私人 SQLite/.vltrain；公开训练权重可能保留训练信息，不能宣称其隐私风险为零。

## 一、模型谱系与实验性质

| 代次 | 主要变化 | 权重/样本数量 | 研究结论 |
|---|---|---|---|
| R01 | 独立 26D LightGBM 排序器，不从真实 V9 权重开始 | 基础研究森林 | 仅兼容性起点 |
| R02 | 沿 R01 增量训练 | 静态排名；旧版私人历史样本 Top-1 83.92% | Top-3 相比 R01 略降，未晋级 |
| R03 | 从 R02 增训 12,000 组合成局面 | 194 棵树；23,038 训练组 / 340,229 候选行 | 固定 60 战术题 57/60；不代表 V9 权重更新 |
| R04 | 纠正真人对局的先后手识别并增加真实来源训练 | 239 树 / 26D；11,685 组 / 143,778 候选 | 3,293 留出组 Top-1：2,614；研究基准 |
| R05 | 加入 MIT WinePy 少量自博弈开源记录，继续训练 | 240 树；12,248 组 / 151,099 行 | 私人 Top-1 下降两组；未晋级 |
| R06 | 扩展 156 份开源记录和 72,000 新合成战术局面；另从零研究 34D 特征 | 319 树研究候选 / 1,674,475 候选行 | 战术有所改善，但私人 Top-1 回归；1,024 局研究对抗 503:503（18 和） |
| **R07** | 从 R04 精确保留的 239 树扩到 34D，再分阶段残差续训 | **249 树最佳候选；37,123 组 / 666,475 行** | **9 道门禁仅过 8 道**；1024 局不能证明胜率提升 |

这里的“真人棋谱”指用户提供的本地原始记录，重复备份去重与独立重复战术出现保留是两回事；合成局面不是新的人类对局。没有认证过对手身份的自述成绩不能转换成 Elo。

历史落点仅是实际下过的着法，**不是已认证最佳着法**。原始 7 份私有快照包含 5,356 个接受的完整终局事件；公开的 WinePy 156 份源记录只有 **122 条不同的完整落子序列**。R07 训练组构成为 11,685 私人来源 + 1,438 开源来源 + 24,000 合成 = **37,123**，对应 666,475 条候选评分行，**绝非 666,475 局独立比赛**。

R07 扩展 26D 基座时在 256 组探针上的最大预测差为 **0**，保证原始树的输出没有因接口扩展而意外变化。五个增量检查点为 244/249/259/274/289 棵；均未满足所有晋级门槛。R07-249 的 SHA-256 为 `d4cea7f62e9e8ffc119d60861ce05df43aafdbdc280b51707dc1b7e40e5fc234`，研究权重 **34D**，与当前 V9 原生 **26D** 接口不兼容。

## 三、真正完成的 1,024 局研究对抗

R07-249 与 R04-239 在**相同静态 LightGBM 排序环境**（Alpha-Beta 深度 0、共用立即胜利及唯一必防规则）打满 **512 对开局、交换黑白，共 1,024 局**。

- R07 胜 **505**，R04 胜 **501**，和 **18**，R07 计和棋得分率 **50.1953%**。
- **504/512** 对交换先后手的开局双方得分相等；R07 双胜 5 对，R04 双胜 3 对。
- 对交换颜色配对进行自助抽样，R07 得分率 **95% 区间约 49.71%–50.78%**，包含 50%。
- 本地静态排名延迟 P50：R04 **0.861 ms**；R07 **0.856 ms**。这**不是** iPhone 搜索耗时。
- **正式 V9 原生配对搜索比赛为 0 局**。不得据此给 R07 确定性 Elo 或部署资格。
